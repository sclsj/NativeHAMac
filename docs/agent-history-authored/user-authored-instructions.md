# Provenance-corrected user instruction ledger

This ledger consolidates only the second-pass provenance audits in this directory. It does not use the earlier first-pass reports or proposal as evidence. “Eligible” means that the semantic core was classified as direct, high-confidence user authorship, or that a mixed candidate contains a precise user delta which the audit explicitly permits retaining. Eligibility does not turn a task-specific request into a repository-wide rule.
